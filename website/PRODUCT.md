# Product

## Register

brand

## Users

在 Mac 或 Windows 上大量写字的人：开发者、写作者、做内容的人。多数从小红书、抖音的宣传片或 GitHub 过来，
想在一两分钟里判断三件事：好不好用、要花多少钱、数据安不安全，然后下载。中文用户为主，英文用户其次。

## Product Purpose

OrangeSpeakEasy 是开源免费的语音输入与翻译工具，口号"口述成文，划词即译"。三项功能各由一个快捷键唤起：语音输入（口述，
整理好的文字写进当前输入框）、语音翻译（说一种语言，写出另一种）、划词翻译（选中任意文字，译文显示在选区下方）。
官网照 README 的叙事：先讲三项功能，再把"自由"讲清楚：模型自由（接主流各家、自带密钥，划词另选文字模型）、
方式自由（直出、混合、离线三种，管语音输入和语音翻译）、硬件自由（Apple 芯片、Intel、Windows）、
隐私自由（语音输入可以完全不上传）、费用自由（每月几块钱，或一分不花）。成功的标准是看完就下载。

## Brand Personality

简洁、干练、可信。像 Apple 的产品页：纯白底、大字、真截图，数字说话。书面语，短词短句，言简意赅；不口语、不俏皮、不卖弄。

## Anti-references

- AI 生成落地页的样子：渐变光晕、玻璃卡片、每段上面一行大写小字、一排一模一样的图标卡片、流水账式居中堆叠。
- 按钮里再套胶囊、说明出处和免责的小字、用删除线表示"删掉了"、看不懂的点阵图。
- 不提 Typeless，不和任何订阅产品比价。

## Design Principles

1. 截图和数字代替形容词：每一段都要有真东西可看（真窗口截图、实测数字、厂商标志）。
2. 一段一个主张：内容撑得起一段的单独成段，一句话讲得完的并进一排小特性。
3. 节奏有起伏：每段的版式不同，不同样大小地往下摞。
4. 主次分明：主流的放主位（Apple 芯片、Windows），次要的退一步（Intel），但不藏起来。
5. 讲好不讲坏，但只讲实测过的。

## Accessibility & Inclusion

WCAG 2.2 AA：正文对比度 ≥ 4.5:1，焦点可见，图片有说明；所有动效有"减弱动态效果"的替代；中英双语，跟随浏览器语言。
